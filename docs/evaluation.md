# Evaluation protocol, fixed before training

goodbooks-10k has no interaction timestamps. Its publisher describes the file as time sorted, but individual times cannot be audited. This build uses source file order as an ordering proxy and never calls the holdout a verified temporal split. Book metadata and tags are an undated snapshot. They support the interactive content fallback and descriptive genre metrics, not the collaborative model's training features.

The bounded demonstration uses catalog book IDs 1 through 1,000 and the first 300,000 rows of the pinned public ratings file. This favors popular books and early source records and is not representative of the complete catalog. Ratings of at least four are binary positives. All observed training ratings, including dislikes, are excluded from candidate lists. Source rows below 240,000 form training; later source rows form the holdout. No holdout rating enters popularity, cooccurrence, or factor learning.

The headline evaluation samples at most 500 eligible readers with at least five positive training items and at least one unseen positive holdout item, using seed 20260926. Every eligible unseen catalog item is ranked, with ID as a deterministic score tie break. Recall@200 measures candidate retrieval; NDCG@10, Recall@10 and hit rate@10 measure ordering. This is exact full-catalog evaluation of the implemented scorers, not a separately learned two-stage ranker. The blend is fixed before training: 0.55 normalized cosine, 0.35 normalized ALS, and 0.10 normalized popularity. No held-out model selection or hyperparameter tuning is performed.

Popularity counts positive training interactions. Item cosine uses binary user-item columns, cosine normalization, and sums neighbors over the user's positive training history. Implicit ALS uses weighted squared loss, confidence 1 + 20r, 16 factors, regularization 0.1, six alternating iterations, and seed 17. Each observed positive is binary. Cold readers use training popularity when they have no positive training history.

Intervals are percentile 95% bootstrap intervals from 1,000 user resamples. The same user index draws support paired NDCG differences. All six pairwise comparisons share one Benjamini-Hochberg family at false discovery rate 0.05, using two-sided paired random sign permutation p-values with 4,999 permutations. A corrected winner must beat every other model with positive paired difference and corrected p < 0.05. Otherwise the observed leader is explicitly not a corrected winner.

Two diagnostic shortcuts are kept separate. A seeded random 80/20 interaction split retrains the same model definitions and evaluates its own eligible reader population; differences therefore mix split and cohort changes and are not a causal leakage estimate. Sampled ranking uses every holdout positive plus 100 sampled unseen negatives from the same ordered-split readers. Sampling seed 61 and candidate sets are shared across models. Full ranking remains the headline protocol.

Cold-reader slices report 0-4 positive training interactions separately, with at most 200 readers sampled using the same fixed seed. Cold-item recall considers holdout positives with zero positive training count; absent slices are marked unavailable. Long-tail items are the lower 80% of catalog items by training popularity. Novelty is negative log2 of add-one-smoothed training popularity. Observed catalog coverage is a deterministic aggregate, stored as coverage.mean and observed_coverage. The accompanying low/high values describe a separate central 95% range of conditional reader resamples, not a confidence interval. The observed point may exceed this range: a distinct-count bootstrap cannot invent unseen items and usually loses some rare recommendations. expected_resampled_coverage separately records the average resampled value. Intra-list diversity is one minus item cosine. Genre calibration uses Jensen-Shannon divergence between smoothed history and recommendation genre distributions; genre labels are descriptive snapshot metadata. Exported reader histories preserve source-row order among the last twelve positive training interactions; this is still an ordering proxy, not a verified reading chronology.

The serving re-ranking diagnostic uses a seeded 100-reader subset, the top 200 blend candidates, an author cap of two, MMR weight 0.25, and calibration weight 0.2. The exact serving functions generate each stage. Popularity appears as a baseline on this same subset. This table uses the serving function's tag Jaccard diversity and unsmoothed natural-log Jensen-Shannon divergence; those definitions differ from the main model comparison and must be labeled separately. No exploration slot or online effect is evaluated.

OPE uses a finite simulator with 12 equally likely contexts and six actions, a known reward table, a full-support logging policy, and a fixed softmax target policy. Exact value is computed by enumerating contexts and actions. Each sample size (250 and 1,000) runs 200 independent seeds. IPS, SNIPS, DM, and DR are implemented locally, with 200 bootstrap draws per log sample. Reward predictions are either the simulator's oracle table or a deliberately constant 0.2 table. The oracle DM benchmark is not a learned reward model. Bias, variance, RMSE, interval coverage, and Monte Carlo uncertainty are published. Coverage uncertainty uses a 95% Wilson binomial interval, including when no seed covers truth. Simulator evidence does not establish online benefit or identify policy value from browser logs without support.

The real Open Bandit check uses the pinned all-campaign sample, separately for each display position. The first chronological half of random-policy logs fits a smoothed action reward model and a fixed policy placing 80% of its probability on the highest training-CTR action plus 20% uniform exploration. The second half evaluates that explicit target and a uniform sanity check using 1,000 row bootstrap resamples. This is a different target from the contextual BTS policy, whose full action probabilities are not reconstructed from marginal action frequencies. Observed BTS reward in its own second-half logs is descriptive context, never target-policy truth. Row bootstrap ignores repeated-reader dependence. Per-position marginal propensities are not joint-slate propensities.

These are demonstration recommendations on a public dataset; no real reader's identity is present and no recommendation is personalized to a real person.
